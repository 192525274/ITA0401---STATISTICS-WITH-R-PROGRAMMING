## PROGRAM
``` R PROGRAM
# Create vectors
v <- c(10, 20, 30)

# Create a matrix
m <- matrix(1:6, nrow = 2, ncol = 3)

# Create a function
f <- function(x) {
  return(x * 2)
}

# Create a list
mylist <- list(Vector = v, Matrix = m, Function = f)

# Display list contents
print(mylist)

# Call the function
print(mylist$Function(5))
```
